Los túneles gratuitos de Cloudflare están pensados para HTTP. Para Minecraft, tus amigos deben instalar cloudflared y ejecutar el comando que aparece abajo; después se conectan a 127.0.0.1. Si no funciona, usa UPnP o abre el puerto manualmente.

Tus amigos ejecutan ese comando y en Minecraft ponen 127.0.0.1:25565.

¿Prefieres abrir el puerto a mano en el router?
  1. Entra en el panel de tu router (normalmente 192.168.1.1 o 192.168.0.1).
  2. Busca Port Forwarding, Reenvío de puertos o NAT.
  3. Crea una regla para el puerto indicado.
  4. Asigna la IP local de este PC como destino.
  5. Comprueba que el firewall de Windows permita Java o el servidor Bedrock.
